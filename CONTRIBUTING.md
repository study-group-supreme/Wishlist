# 🤝 Bidrag til Bæredygtig Ønskesky

Tak fordi du overvejer at bidrage til projektet! 💚

Dette projekt handler om at gøre ønskelister mere bæredygtige, og alle bidrag er med til at styrke den vision.

---

## 📌 Sådan kommer du i gang

1. Fork dette repository
2. Klon din fork lokalt

```bash
git clone https://github.com/dit-brugernavn/Wishlist.git
```

3. Opret en ny feature-branch

```bash
git checkout -b feature/dit-feature-navn
```

---

## 🛠️ Opsætning af projekt

Projektet er bygget med Java (Spring Boot) og bruger MySQL.

Sørg for at du har:

* Java 17+ installeret
* Maven installeret
* MySQL kørende lokalt

Kør projektet med:

```bash
./mvnw spring-boot:run
```

---

## 🧩 Retningslinjer for bidrag

For at holde kodebasen ren og konsistent:

* Skriv klar og læsbar kode
* Følg eksisterende struktur (controller, service, repository)
* Tilføj tests til ny funktionalitet
* Undgå duplikeret kode
* Hold commits små og fokuserede

---

## 🧪 Tests

Alle nye features bør testes.

Kør tests med:

```bash
./mvnw test
```

---

## 🌍 Fokus på bæredygtighed

Når du udvikler nye features, så spørg dig selv:

* Gør dette forbruget mere ansvarligt?
* Kan funktionen hjælpe brugeren til grønnere valg?
* Er data/modellen nødvendig og effektiv?

---

## 🔄 Pull request proces

1. Push din branch

```bash
git push origin feature/dit-feature-navn
```

2. Opret en Pull Request
3. Beskriv tydeligt hvad du har lavet
4. Vent på review og feedback

---

## 🐛 Bug reports

Hvis du finder en bug:

* Opret et issue

* Tilføj steps til at reproducere fejlen
